Five decisions, not fifty guidelines

Everything below follows from these. When something new needs designing and it isn't covered here, it should still feel like it agrees with this list.

One accent, earned

Signal violet marks the single most important thing on a screen: the primary action, the thing that changed. It is not the default color of every button.

Data is legible at a glance

IDs, timestamps, amounts and counts are set in monospace with real tabular alignment. Numbers you're meant to compare should look comparable.

Two radii, nothing between

7px for controls you click, 18px for surfaces you read. No 8px-here-12px-there drift. If it isn't one of these two, it's wrong.

Motion answers an action

Things animate because a person did something, or because the system is showing what changed. Nothing fades in on scroll just to seem alive.

Dark by default, light in full

The product's native mode is dark. Light mode is a complete second surface, not an inverted afterthought, built and checked alongside it.

Typography

Space Grotesk carries the voice: confident, a little technical, never soft. Inter does the actual work of being read at small sizes. JetBrains Mono is reserved for real data, not for decoration.

Logo & marks

One mark, used consistently rather than redrawn per surface. It needs to survive at 16px in a browser tab as well as it does at hero scale.

Iconography

A single-weight line set, 1.5px stroke, no fills. Nothing decorative, every icon maps to a real action or object in the product.

Module icons
